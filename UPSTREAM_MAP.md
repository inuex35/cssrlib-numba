# Where upstream went

Generated by `python ci/upstream_map.py`. Do not edit by hand.

Upstream baseline: `5e0cfb3` -- Merge pull request #90 from hirokawa/devel

This branch cannot take upstream changes by merging -- it is 86
commits ahead of `origin/dev` with nothing behind it, and `git diff
-M50%` finds no renames at all between the two trees, because the
layer split rewrote the files instead of moving them. Porting an
upstream change means finding the code by name and applying it by
hand. This table is that lookup.

Matching is by symbol name, so a symbol renamed on the way in reads
as `absent` and a common name reads as `ambiguous`. Methods are also
looked up by their bare name, because the class half is what the
split changed: one god class became four mixins.
